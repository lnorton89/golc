<objective>
Execute PowerShell removal plan Step 7 in full: delete `golc.ps1` and retire every reference to it, closing the migration this session's earlier quick tasks (Steps 0-6, 8) built toward.

Purpose: `golc.ps1` (811 lines) had been fully superseded by Mage and the pinned `golc-project.exe` CLI binary as of Step 6, but remained the file itself, plus five PowerShell acceptance scripts, two CI workflows, and dozens of doc comments/error messages still describing it as the entrypoint.
Output: `golc.ps1` deleted; `commands.entrypoint` removed from every layer that declared it; `check.yml` and `linear-sync.yml` rewritten to Mage; the acceptance-test suite investigated and either deleted (redundant), ported to Go (genuine gap), or kept as PowerShell (architecturally can't be Go).
</objective>

<context>
This quick task's investigation methodology differed deliberately from a mechanical "port every .ps1 line to Go" approach: each of the five `tests/acceptance/*.ps1` scripts was read in full and its exact behavioral assertions cross-referenced against the existing Go test suite (via targeted grep for the exact error codes/markers each script checked) before deciding its fate. Three outcomes resulted, not one:
- **Delete outright** (`bootstrap.ps1`, `bootstrap-node.ps1`'s control-flow assertions, `offline.ps1 -Mode package`, `walking-skeleton.ps1 -Mode red`/`-Mode bootstrap`): fully redundant with existing `internal/bootstrap`, `internal/delivery`, `internal/projectconfig` unit tests, confirmed by exact cross-reference, not assumption.
- **Port to Go** (`offline.ps1 -Mode core`, `walking-skeleton.ps1 -Mode green`, `linear-transport.ps1 -Mode workflow`'s structural checks): a genuine, previously-uncovered gap existed (no Go test ever called the real routes against the real repository, or ever ran the real compiled binary as a real subprocess, or ever read `linear-sync.yml`).
- **Keep as PowerShell** (`linear-transport.ps1 -Mode hierarchy`/`-Mode readfailure`): architecturally cannot be replicated in Go without spawning a real Node process running the real compiled `tools/linear-sync` adapter; its `golc.ps1` dependency was fixed instead of the whole script being ported or deleted.

A live functional dependency was also found and fixed along the way: `.claude/settings.json`'s Stop hook shelled out to `golc.ps1` for its quick-test gate, which would have silently broken the moment the file was deleted.
</context>
