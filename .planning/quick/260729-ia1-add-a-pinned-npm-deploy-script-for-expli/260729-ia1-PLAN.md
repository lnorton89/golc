| Boundary | Description |
|----------|-------------|
| npm registry → repository toolchain | A third-party CLI and its dependency graph enter the development/deployment environment. |
| CI artifact → committed visual baselines | Untrusted report attachments can replace repository acceptance images only after name/hash mapping and visual inspection. |
| Local repository → GitHub Actions | The pushed site SHA becomes the immutable input to remote Linux verification. |
| Local authenticated CLI → Netlify production | A command can mutate the public production site linked by `.netlify/state.json`. |
| Netlify deploy result → user-visible site | A successful command is insufficient unless the canonical route serves and behaves as expected. |
| Site submodule → parent repository | The parent gitlink must record an existing, pushed site commit rather than uncommitted or unrelated state. |
