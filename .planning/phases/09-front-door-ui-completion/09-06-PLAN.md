## Phase Goal

**FLAGGED — MVP user-story format discrepancy** (see 09-01-PLAN.md). ROADMAP goal, verbatim:

> A new operator can go from a fresh checkout to a patched fixture and a scene on screen using only
> the UI, with Guided First Show onboarding as the on-ramp — no CLI required for the happy path.

This plan's slice: the operator can actually import a catalog fixture into their library, on screen,
after seeing exactly what they are getting.

<objective>
Add preview-then-commit import for Open Fixture Library fixtures: inspect the candidate inline, see
its lossy-import warnings, then commit it with one confirm action (D-02).

Purpose: FDUI-01's import half. Plan 09-05 made the catalog searchable and made import artifacts
visible in the library; this plan lets the operator actually perform the import from the workspace
instead of the command line, and does it in the order D-02 requires — inspect first, commit second.

Output: `FixtureLibraryService.PreviewOFL` / `.CommitPreview`, their bridge wrappers, and the
workspace's candidate panel with the "Add to Library" confirm action.
</objective>

  <action>
Add to `FixtureLibraryService` a preview directory resolved once as a dedicated subdirectory that is NOT the library directory and is not scanned by `ListDirectory` — put it under the OS temp directory keyed to this service instance, created lazily.

`PreviewOFL(manufacturerKey, fixtureKey string) (FixturePreviewView, error)`:
1. Create the preview directory if needed and choose a preview file path inside it.
2. Forward to `s.execute([]string{"fixture", "import", "--ofl", manufacturerKey + "/" + fixtureKey, "--out", previewPath})` — the existing route, unchanged. The Wails layer performs no fetch, no normalization, no pinning, and no validation of its own.
3. On a non-zero exit code, return a view whose inspect part carries `valid:false` and `errors` built from the non-empty trimmed stderr lines, with a nil error. Clean up any partial preview file.
4. On success, read the written artifact and decode it with `fixture.DecodeEnvelope`, then `fixture.Pin` its definition for the stable key, content hash, and revision, and project the envelope's provenance source, validation result, and warnings into the existing `FixtureInspectView` shape. Warnings are always a non-nil slice.
5. Return the preview token (the preview file path), a suggested library file name derived from the manufacturer and fixture keys with a `.json` extension matching the artifact the import route writes, and whether that destination already exists in the library directory.

`CommitPreview(previewToken string, overwrite bool) Result`:
1. Reject any token that does not resolve to a path inside this service's own preview directory, with `GOLC_WAILS_FIXTURE_PREVIEW_UNKNOWN`, before touching the filesystem — resolve both sides to absolute, cleaned paths and compare with an explicit prefix check on a path-separator boundary, never a bare string prefix.
2. Compute the destination inside the library directory from the previewed artifact, create the library directory if needed, and if the destination already exists and `overwrite` is false, return a non-zero `Result` carrying `GOLC_WAILS_FIXTURE_IMPORT_EXISTS` and write nothing.
3. Otherwise move the previewed file to the destination so the committed bytes are exactly the bytes the import route produced. Do not re-encode, do not re-marshal, do not re-pin.

`DiscardPreview(previewToken string) Result`: the same containment check, then remove the preview file. The workspace calls it when the operator changes selection or switches source, so an abandoned preview never accumulates.

In `wailsBridge.ts`, add the `FixturePreviewView` type, extend `FixtureLibraryServiceBinding` with the three methods, and export `previewOflFixture`, `commitFixturePreview`, and `discardFixturePreview` following the existing never-throw contract — the two mutating calls return `bridgeUnavailableResult()` when the binding is absent, exactly like `saveShow` does.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-06-01 | Tampering | `CommitPreview` writing outside the preview/library directories via a crafted token | high | mitigate | Both sides are resolved to absolute cleaned paths and compared with an explicit separator-boundary containment check before any filesystem operation; a token outside the service's own preview directory is refused with `GOLC_WAILS_FIXTURE_PREVIEW_UNKNOWN`. | T-09-06-02 | Tampering | Silent destruction of a hand-authored library fixture | high | mitigate | An existing destination is refused with `GOLC_WAILS_FIXTURE_IMPORT_EXISTS`; replacement requires an explicit second, operator-initiated action |
