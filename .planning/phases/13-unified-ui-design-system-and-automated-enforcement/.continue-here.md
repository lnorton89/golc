## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---|---|---|---|
| Environment-only WebView2 debugging | It never reaches `msedgewebview2.exe` under Wails v2. | blocking | Preserve and run the committed proof-only local-module/overlay bridge from `82541bc4`. |
| Broad visual-policy exceptions | Fixture and scene migration initially exposed hundreds of legacy violations. | blocking | Convert directory-owned code in bounded passes; add focused tests and require scoped DS checks to pass. |
| Faking packaged evidence | Browser success is insufficient for the shipped desktop contract. | blocking | Keep `dialog-feasibility.json` fail-closed and rerun the packaged proof after seam changes. |
| CSS shorthand mixing a raw literal with a `--ds-*` token | `border: 1px solid var(--ds-border-default)`, `outline: var(--ds-focus-ring) solid var(--ds-focus-color)`, and multi-value `padding`/`transition` all fail DS001's strict single-`var()`-value check even though every operand is a valid token. | recurring | Split into longhand sub-properties (`border-width`/`border-style`/`border-color`, `outline-width`/`outline-style`/`outline-color`, `padding-block`/`padding-inline`) so each individual declaration is exactly one `var(--ds-*)`. |
