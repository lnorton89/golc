**As an** integrator, **I want to** inspect and control every public GOLC capability through a secure, versioned, revision-aware HTTP API, **so that** external programs behave exactly like the desktop application.

> User story derived from REQUIREMENTS.md §"User Stories" ("As an integrator, I can control every supported capability through stable TypeScript and external APIs that behave like the desktop UI"). <objective>
Pin the three new Go module dependencies this phase's API server is built on — Chi (router, D-04), Huma v2 (OpenAPI-from-Go, D-03), and golang.org/x/time (per-key rate limiting) — as reviewed, offline-verified go.mod/go.sum entries, gated by a blocking supply-chain verification checkpoint.

</objective>
