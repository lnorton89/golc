Contradicts the phase's own documented D-10 "never a silently missing gap" guarantee. Suggested fix (07-REVIEW.md CR-01): give `ringEvent` a strictly monotonic sequence number independent of `show.State.Revision`, used for the SSE `id:` line and replay comparisons.

Fix: fire `MutationEvent{Outcome: "failure", ...}` for each translate/scope failure inside the pre-flight loop, mirroring `mutate.go`'s own branch.
