## Phase Goal

**As an** integrator, **I want to** inspect and control every public GOLC capability through a secure, versioned, revision-aware HTTP API, **so that** external programs behave exactly like the desktop application.

<objective>
Publish the API's contract: generate the OpenAPI 3.1 document from the Go handler structs (D-03), commit it with a drift check (mirroring internal/contracts), document typed errors, and write the compatibility/deprecation policy (D-02). After this capstone slice, a client can generate against a published contract, handle typed errors, and understand the versioning/deprecation guarantees — and the capability-coverage gate is fully closed.

Purpose: API-02 (OpenAPI contract, generated client examples, typed errors, compatibility/deprecation guidance). Runs last so the contract covers every operation added by 07-04..07-08.
Output: committed openapi.json + drift test + COMPATIBILITY.md + deprecation header mechanism.
</objective>
