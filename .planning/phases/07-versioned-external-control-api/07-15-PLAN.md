## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated client → /v1/batch locked section | A client-controlled batch crosses `mutationMutex` and touches a real (throwaway) copy of the show; from here on, every failure is a failure of an attempt that reached the transactional core |
| mutation attempt → audit_log | The audit trail is the only durable record that an attempt occurred; a failure path that skips it is invisible to every later investigation, including incident response and non-repudiation disputes |
| concurrent external writer (CLI/Wails) → the real show | An out-of-process writer can advance the revision between a batch's start and its commit; the resulting 412 is the API's own evidence that it declined to overwrite someone else's work |
