## Phase Goal

**As an** integrator, **I want to** inspect and control every public GOLC capability through a secure, versioned, revision-aware HTTP API, **so that** external programs behave exactly like the desktop application.

<objective>
Make the /v1 server able to safely mutate the show: scope-gated, revision-checked (If-Match, D-13), dry-run-able (?dry_run=true, D-14), and idempotent (Idempotency-Key). All mutations pass through one serialized critical section (Pitfall 2) and fire a post-mutation observer seam that audit (07-07) and SSE (07-08) attach to.

Purpose: the invoke half of API-01 and the core of API-04. Establishes the mutation pipeline and the single post-mutation hook the rest of the phase depends on.
Output: mutating REST operations with optimistic concurrency, dry-run previews, idempotency, and the observer seam.
</objective>
