## Phase Goal

**As an** integrator, **I want to** inspect and control every public GOLC capability through a secure, versioned, revision-aware HTTP API, **so that** external programs behave exactly like the desktop application.

<objective>
Deliver the revisioned server-sent event stream (D-09/D-10/D-11/D-12): one global `GET /v1/events` carrying every domain change tagged by type and keyed by monotonic revision, with a bounded replay buffer and `Last-Event-ID` recovery that surfaces a gap as an explicit `resync` signal (never silently dropped events).

Purpose: API-03 (revisioned SSE + gap recovery by re-querying authoritative state). The stream is a hint stream, not the source of truth — it publishes off 07-05's post-mutation observer seam so it reflects both single mutations (07-05) and atomic batches (07-06).
Output: `/v1/events` SSE endpoint with ring-buffer replay, resync-on-overflow, all-clients broadcast, and a revocation tick.
</objective>
