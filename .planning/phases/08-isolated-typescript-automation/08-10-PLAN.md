## Phase Goal

**ROADMAP goal (verbatim):** Users can create and debug typed TypeScript automation in a supervised, capability-limited process that cannot own or delay deterministic output.

> **MVP-mode note:** see 08-01-PLAN.md's Phase Goal section.

**This plan's slice:** after this plan, a user runs and stops scripts from the app, reviews and adjusts their capability profile in the launch dialog, and watches logs and per-call outcomes stream live — with a persistent, explanatory stopped banner when a run ends.

<objective>
Deliver the GUI half of SCRP-04 and SCRP-05: the Run/Debug launch dialog (D-07, D-09), the toolbar launch/stop actions (D-10), and the live debug panel with its terminal states (D-04, D-05, D-08, D-12, D-13, D-03's trace rendering).

Purpose: every enforcement mechanism built in 08-06 through 08-09 is invisible until a user can see the profile they are launching with and read why a run stopped. This plan is where the phase becomes legible.
Output: the two Scripts components, their tests, and the extended workspace and bridge.
</objective>

## STRIDE Threat Register

Grounded in 08-RESEARCH.md §Security Domain "Sensitive data leakage through captured script stdout/stderr" row and ASVS V5.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-45 | Tampering | rendering script output | high | mitigate | Log lines, outcome messages, and stack frames are rendered as React text children only — never through `dangerouslySetInnerHTML` and never into an `href`/`src` attribute — so attacker-controlled script output cannot inject markup or a navigable URL into the webview. |
| T-08-46 | Elevation of Privilege | profile editing | medium | mitigate | The dialog's numeric constraints are convenience only; the backend re-resolves and re-validates every limit (08-06's `Enforce`/`ResolveResourceLimits`), so an edited or tampered client value cannot widen an enforced limit. Scope options are limited to the three persisted enum values. |
| T-08-47 | Information Disclosure | rendered diagnostics | medium | mitigate | Every event payload was already redacted at 08-08's single publication point, so the panel renders redacted text by construction; the frontend performs no additional un-redaction. |
| T-08-48 | Repudiation | dismissed terminal state | low | accept | Dismissing the banner clears the local panel view only; the run's audit rows and events remain durable in the show's audit trail and the event ring. Accepted because the durable record is unaffected. |
| T-08-28 | Elevation of Privilege | Stop scope creep | high | mitigate | The Stop action calls `stopScript(name)` for exactly the selected script and touches no playback, Art-Net, or global safety surface; the 32px Button treatment plus the doc comment keeps it visually and semantically distinct from Phase 6's global Revoke Automation. |
</threat_model>
