## Phase Goal

**ROADMAP goal (verbatim):** Users can create and debug typed TypeScript automation in a supervised, capability-limited process that cannot own or delay deterministic output.

> **MVP-mode note:** see 08-01-PLAN.md's Phase Goal section.

**This plan's slice:** after this plan, a script author has a real, committed, drift-checked TypeScript type surface describing every GOLC capability a script may call — the contract the editor autocompletes against (08-11) and the host dispatches (08-05).

<objective>
Build `internal/scriptsdk`: a self-registering descriptor registry that deterministically generates the typed GOLC SDK — `golc.d.ts` (ambient global types for Monaco) and `golc-runtime.ts` (the stdio-calling shim the sandboxed process runs) — plus the drift check that keeps the committed output honest (SCRP-02).

Purpose: SCRP-02 requires scripts to reach GOLC only through a generated typed SDK. If the SDK is hand-maintained it silently drifts from the real command surface and either loses capabilities or grows undeclared ones. A registry-driven generator with a completeness gate makes both failures loud.
Output: the `internal/scriptsdk` package, its two committed generated files, and its wiring into `generate`/`check`.
</objective>

## Trust Boundaries
