## Phase Goal

**ROADMAP goal (verbatim):** Users can create and debug typed TypeScript automation in a supervised, capability-limited process that cannot own or delay deterministic output.

> **MVP-mode note:** see 08-01-PLAN.md's Phase Goal section.

**This plan's slice:** after this plan, a user can open the desktop app, navigate to Build → Scripts, create a script, write TypeScript into it, save it, and see it listed with its profile — the first GUI-visible capability of the phase.

**Editor sequencing (not a scope reduction):** this plan's editing surface is a plain bounded `<textarea>` styled to the Technical readout row. D-15's full Monaco language service, live type-checking, autocomplete, and the D-01 breakpoint gutter are delivered in **08-11**, which replaces this textarea in place. Monaco is deferred to its own plan because it requires the generated `.d.ts` (08-03), a `checkpoint:human-verify` for the SUS-flagged `monaco-editor` package, and its own theme reconciliation work — not because any part of D-15 is being dropped.

Bind the `script *` routes into a Wails `ScriptService` and build the Scripts workspace: the D-16 library view, the create/edit/save/delete round trip, and the shell navigation entry.

Purpose: makes the phase's persistence slice real for the user, and establishes the exact component/CSS/test shell that 08-10's run dialog and debug panel and 08-11's Monaco editor extend rather than rewrite.
Output: `internal/wails/svc_script.go`, `ScriptsWorkspace.tsx` + module CSS + tests, and the two-line shell wiring.
</objective>

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-08-12 | Tampering | `SaveScriptSource` argv construction | high | mitigate | Multi-line user source is never interpolated into an argv value; it is written to an `os.CreateTemp` file and passed as `--source-file <path>`, with the temp file removed on return. | T-08-14 | Information Disclosure | rendering error text | low | accept | Wails `Result.Stderr` carries GOLC diagnostic codes, which are non-sensitive by design; the existing `errorMessage` helper is reused unchanged. Accepted because no credential or secret path reaches this surface in this plan. |
