## Phase Goal

**As an** integrator, **I want to** inspect and control every public GOLC capability through a secure, versioned, revision-aware HTTP API, **so that** external programs behave exactly like the desktop application.

<objective>
Add scoped, expiring, revocable API-key authentication (D-05/D-08) and per-key rate limiting to the /v1 server. After this slice, an operator can mint a key from the CLI, an external program must present a valid scoped key on every request, and a compromised key can be revoked and rate-limited.

Purpose: API-05's "scoped authentication for remote access" and the security foundation every mutation (07-05) and the event stream (07-08) rely on. Keys live in the same .golc store as the show (RESEARCH diagram / D-16 storage authority), accessed only through internal/show's single-writer machinery.
Output: api_keys table, key CRUD via CLI + REST, and auth/scope/rate-limit middleware.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| unauthenticated client → /v1 | Bearer key must be validated before any handler runs |
| raw API key → at-rest storage/logs | Secret material must never persist or be logged beyond mint-time |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-04 | Information Disclosure | API key leaked via storage or logs | high | mitigate | crypto/rand token, SHA-256 hash + prefix stored (never the raw key); raw key printed once at mint; no raw-token/hash logging (grep-asserted); ListAPIKeys returns metadata only |
| T-07-05 | Spoofing / Elevation of Privilege | auth bypass or expired/revoked key accepted | high | mitigate | constant-time SHA-256 compare; per-request expiry + revocation check; 401 does not reveal prefix existence; scope gate (D-08) for privileged mutations/mint |
| T-07-06 | Denial of Service | rate-limit exhaustion from a compromised/misbehaving key | medium | mitigate | per-key golang.org/x/time/rate token bucket (60/min, burst 10 default); revocation is the immediate remediation for a compromised key |
| T-07-04b | Tampering | uncoordinated second SQLite connection for key writes | medium | mitigate | key store reuses internal/show openStore (SetMaxOpenConns(1), busy_timeout); no direct sql.Open in apikeys.go (grep-asserted) |
</threat_model>
