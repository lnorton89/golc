## Phase Goal

**As an** integrator, **I want to** inspect and control every public GOLC capability through a secure, versioned, revision-aware HTTP API, **so that** external programs behave exactly like the desktop application.

<objective>
Build the first working vertical slice of the API: a Chi+Huma `/v1` HTTP server, hosted inside the existing Art-Net daemon (D-07), whose handlers translate an HTTP request into a `command.Request` and call the single command execution authority (D-01), returning the same outcome the CLI produces. Deliver real read endpoints plus the capability-coverage gate that makes API-01's "every public capability" claim mechanically checkable.

Purpose: establishes the translation mechanism, the daemon-lifecycle wiring, the import-cycle-safe package boundary, and the operation-registration + coverage seams every later plan builds on.
Output: `internal/api` package with a running loopback `/v1` server, read endpoints, and a passing coverage/parity test.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| external HTTP client → /v1 API | Untrusted request crosses into the daemon that also owns deterministic playback + Art-Net |
| API handler → command execution authority | Translated command args cross into show-mutating/reading logic |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Denial of Service | HTTP handler panic in the daemon process | high | mitigate | chi/middleware.Recoverer on every route; api server runs as an isolated Subsystem goroutine that cannot backpressure or lock the playback/worker path (ARTN-04 invariant) |
| T-07-02 | Tampering / Elevation of Privilege | client-supplied show path → arbitrary file read/write | high | mitigate | translate.go injects the daemon's fixed --show path server-side; no client path field is accepted or forwarded (Pitfall 3) |
| T-07-01b | Spoofing | second command surface bypassing command.Execute | medium | mitigate | internal/api reaches domain logic only via the Executor adapter to command.CommandRegistry.Execute; no direct import of internal/pool/scene/show (enforced by grep gate) |
</threat_model>
